# Eric Delafosse — Portfolio

Personal portfolio site for Eric Delafosse, a business operations analyst. Built with React, Vite, and Tailwind CSS as a deliberate upskilling project alongside real ops and automation work.

## Tech stack

- React 18
- Vite 6
- Tailwind CSS 3.4
- Framer Motion (scroll reveals and section transitions)

## Running locally

```bash
npm install
npm run dev
```

## Build and preview

```bash
npm run build
npm run preview
```

## Lint

```bash
npm run lint
```
